# FAQ

Answers to things visitors ask that aren't covered anywhere else on the site.
Each `##` heading is a question; the paragraph under it is the answer, written
the way you'd say it. The chatbot picks these up on the next rebuild.

Questions the bot couldn't answer also show up as GitHub issues labelled
`kb-miss` — commenting `Answer: ...` there works too, no edit to this file needed.
